# NickForge

**任何 Warband 联机服务器可用的「中文昵称」插件，可实现与X服昵称的同步。**

---

## 安装

### 1. 确认环境

- 服务端：Mount & Blade: Warband **1.174** 专用服务器
- 引擎：服务端必须使用高版本 **WSE2 **（1.1.5.3+，低版本不保证兼容）
- 模块：任何模组均可使用本插件，理论兼容所有MOD。（已在Native、拿破仑战争、戚家军、全面入侵2测试通过）

### 2. 复制文件

把本仓库的 `lua` 文件夹放进你的模块目录，最终结构如下：

```
Modules/
└── 你的模块/
    ├── module.ini
    ├── ...
    └── lua/
        ├── main.lua      ← WSE2 启动时自动执行
        └── rename.lua    ← 插件本体
```

### 3. 验证

启动后在控制台发现此行说明安装成功：

```
[Rename] 昵称系统已挂载 x 个任务模板  后端地址=http://...
```

玩家进服时会出现：

```
[Rename] 改名: player=1 guid=1234567 -> 安以陌
```



## 注意事项

- **必须用 WSE2 启动服务器。** 修改昵称函数由WSE 2引擎提供，原版服务端不支持本插件。
- **必须重启才生效。** 安装后必须重启服务器以生效。
- **计分板（TAB）存在生效延迟。** 服务端会立即改名生效。但客户端需要等待引擎事件，在更换地图时完成同步。
